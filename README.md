# ✅ To-Do App  

A simple app to manage tasks efficiently. Add, edit, mark completed, and set deadlines.

## 🚀 Features  

- Add and organize tasks  
- Edit details anytime  
- Mark tasks as **completed**  
- Set **date & time**  

## 🎮 How to Use  

1. Add tasks with details and deadlines  
2. Organize tasks in lists  
3. Edit or mark them as completed
